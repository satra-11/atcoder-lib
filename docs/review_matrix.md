## 運用ルール（おすすめ）

- **結果の記号例**
  - ◎: 即答できた（完璧に定着・これ以上の復習は不要）
  - ◯: 多少時間はかかったが自力でACできた
  - △: 解法は浮かんだがバグらせた、または一部解説を見た
  - ✕: 全く解けなかった（再度解説AC）
- **復習の終了条件**
  - 「翌日」または「1週間後」のタイミングで **◎ (即答)** がついたら、その問題の復習は完了としてOKです。
- **教訓の書き方**
  - 「この問題ではこうする」ではなく、「他の問題でも使えるルール」として言語化する。（例：「ループ変数をiにする」ではなく「二重ループの内側と外側で変数が被らないように注意する」）
