# atcoder Library & Problem Tracker

AtCoder用のアルゴリズムライブラリと、解いた問題の正答記録・復習管理ダッシュボードです。

---

## 過去問・正答記録ダッシュボード (`dashboard`)

Nuxt 3 + Bun + Tailwind CSS + shadcn スタイルで構築されたローカル完結の過去問記録ダッシュボードです。外部サーバーへの公開不要で、すべてのデータはルートの `records.json` に直接保存（Git管理可能）されます。

### 起動方法

```bash
# プロジェクトルートから一発起動
bun run dashboard
```

起動後、ブラウザで **http://localhost:3000** を開きます。

### 主な機能
- **リッチなダッシュボード**:
  - 解答数、自力AC率、要復習問題数、難易度（灰〜赤）分布バーの即時集計
- **直感的な問題記録**:
  - コンテスト名（例: `ABC393`）と問題記号（例: `C`）を入力するだけで問題URLを自動補完
  - AtCoderレーティング色（灰・茶・緑・水・青・黄・橙・赤）＆推定Diff入力
  - 判定結果（AC / 解説AC / WA / TLE / RE / MLE）のワンタップ選択
  - タグ付け、所要時間、思考プロセス・反省点メモ
- **復習管理**:
  - 「要復習」フラグのワンクリック切り替え
  - 要復習問題だけの絞り込み表示
- **高度な検索・フィルター**:
  - キーワード検索（問題名・コンテスト・タグ・反省点メモ）
  - 難易度別・結果別・タグ別の絞り込み
  - 日時順・難易度順・所要時間順ソート
  - テーブル表示 / カード表示の切り替え
- **データ管理**:
  - すべてのデータはルートの `records.json` に即時保存
  - ワンクリックでJSONエクスポート（バックアップ）可能

---

## テスト・ユーティリティコマンド

- `actest <問題名>`: ローカルでのサンプルケース自動判定
- `cio <問題名> [個数]`: サンプル入出力ペアファイルの一括作成
